# 🌍 Smart Air Quality Monitoring

Live air-quality information and forecast using the Open-Meteo API.

**🚀 Live Demo:** https://smart-air-quality-monitor-ntz6apcbs4ezsnuefycafm.streamlit.app/

### ✨ Features
- Live Air Quality Data (PM2.5, PM10, etc)
- City-wise Search (Chennai, Delhi, Mumbai, Nellikuppam)
- Air Quality Trend & Forecast Graph
- Open-Meteo API Integration

### 🛠️ Tech Stack
- Python
- Streamlit
- Open-Meteo Air Quality API
- Pandas, Plotly
